Try to get past it

TIER1-BLOCK Caught by the de-leet and strip pass, matching “ignore previous instructions”.

A 25-rule sample of GuardRail’s Tier 1, in your browser. Nothing is sent anywhere.

Why Tier 2 only monitorsIt over-blocks, so it logs instead.

The classifier blocks 40.4% of benign NotInject prompts against Tier 1’s 0.0%, and no threshold separates them. It logs TIER2-FLAG and doesn’t block, so recall is lower. Blocking is available at POST /validate?tier=2.

How Tier 1 scansTwo passes, then Tier 2 fails open.

Normalized text first, keeping | _ - so markers like <|im_start|> still match. Then a de-leeted, separator-stripped pass, which catches 1gn0r3 prev10us 1nstruct10ns. If Tier 2 errors, the request is allowed.

Latency p50 0.14 ms, p95 26.21 ms, p99 32.11 ms on local docker compose and CPU. Tier 1 alone p50 0.09 ms.

The held-out rules were written after I had seen the full corpus, so the refit isn’t perfectly blind. That bias is optimistic, so read 0.7895 as an upper bound.

Against Llama-Guard-3-8BLlama Guard missed 165 of 190. Its taxonomy doesn’t cover injection.

GuardRail, in-sample: recall 1.0000, precision 1.0000, p50 0.16 ms. Llama Guard: recall 0.1316, precision 1.0000, p50 1708 ms on local Ollama and a GTX 1650. Not a fair win, because its S1 to S13 taxonomy doesn’t cover prompt injection.

CVSS 9.9Sandbox escape in smolagents (CWE-94)Disclosed via huntr

A code-injection flaw in the agent sandbox let arbitrary commands run on the host. Disclosed to the maintainers through huntr.

HighPath-traversal bypass in Aikido firewall-javaVia Intigriti

A payload that got past the firewall’s path-traversal detection and still worked as a traversal.

CriticalCORS origin reflection to account takeoverClosed: duplicate (valid)

A REST API reflected any Origin while returning Access-Control-Allow-Credentials: true. The session cookie was scoped to the root domain without HttpOnly. One visit to a malicious page pulled profile data, API keys and marketing contact databases as the logged-in user. Fix: a server-side origin allowlist at the gateway, plus HttpOnly.

CriticalUnauthenticated GraphQL user enumeration, 57M recordsClosed: duplicate (confirmed valid)

Introspection was off, but validation errors exposed a Relay-style users connection with unauthenticated cursor pagination, no rate limit and no depth cap. totalCount returned 57,316,627, confirmed live by a delta of 209,852 accounts over eight days. A full export was reachable in roughly 32 hours at 10 req/s.

HighUnrestricted Google Maps API keys in page sourceTriaged duplicate, P4

Two keys hardcoded in served HTML and a webpack bundle, with no referrer, IP or API restriction. A controlled 50-request test returned 50/50 OK with no throttling, roughly $121/hour of billable abuse from one workstation. CWE-798, OWASP API4:2023.

InformativeDangling Route53 delegation to subdomain takeoverClosed: theoretical exploitability

Certificate transparency showed a staging subdomain with live NS delegation into an abandoned Route53 zone (SOA serial=1). Deleted zones’ nameservers return to a shared pool, so any AWS account could reclaim authority, and the session cookie was root-scoped. Of 11 NXDOMAIN candidates checked with passive DNS and Wayback CDX, one was still delegated.
