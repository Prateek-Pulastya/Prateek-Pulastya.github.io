Why Tier 2 only monitorsIt over-blocks, so it logs instead.

The classifier blocks 40.4% of benign NotInject prompts against Tier 1’s 0.0%, and no threshold separates them. It logs TIER2-FLAG and doesn’t block. The cost is lower recall. Blocking is available at POST /validate?tier=2.

How Tier 1 scansTwo passes, then Tier 2 fails open.

Normalised text first, keeping | _ - so markers like <|im_start|> still match. Then a de-leeted, separator-stripped pass, which catches 1gn0r3 prev10us 1nstruct10ns. If Tier 2 errors, the request is allowed.
